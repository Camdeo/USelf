# USelf Alpha — рабочая тестовая версия

Это функциональная Alpha для первого реального прохождения двумя людьми.

## Что уже реализовано

- создатель вводит только свои имя и возраст;
- создатель выбирает темы и создаёт тест;
- создаются две разные приватные ссылки: своя и для партнёра;
- партнёр по своей ссылке видит приглашение и самостоятельно вводит имя/возраст;
- в тест попадает один и тот же замороженный набор вопросов для обоих;
- подключён финальный банк USelf: 312 вопросов, 7 тем;
- вопросы идут длинным списком, сгруппированы по темам и блокам;
- Да / Возможно / Нет; вопрос можно оставить без ответа;
- повторный клик по выбранному ответу возвращает вопрос в состояние «пропущено»;
- комментарий закрыт по умолчанию и раскрывается по кнопке;
- ответы и комментарии сохраняются на сервере сразу;
- тест можно закрыть и продолжить позже по той же приватной ссылке;
- завершить можно с любым количеством пропусков;
- общий результат открывается только после завершения обоих;
- в результате видны конкретные ответы и комментарии обоих;
- цвета: Да+Да — зелёный; комбинации без «Нет» с «Возможно» — синий; любое «Нет» — красный; пропуски без «Нет» — нейтральный;
- компактные цветные «облачка» результата сохранены.

## Локальный запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r backend/requirements-dev.txt
uvicorn backend.app.main:app --reload
```

Открыть: http://127.0.0.1:8000

По умолчанию используется локальная SQLite-база `uself_local.db`. На Render автоматически используется PostgreSQL через `DATABASE_URL`.

## Проверки

```bash
pytest -q
```

Тесты проверяют реальный банк из 312 вопросов, выбор тем, самостоятельный профиль партнёра, пропуски, комментарии, блокировку результатов до завершения обоих и матрицу цветов результата.

## Деплой

Файл `render.yaml` создаёт один Web Service и одну PostgreSQL-базу. Frontend — обычные HTML/CSS/JS и отдаётся тем же FastAPI, поэтому Node/npm для Alpha вообще не нужен.
